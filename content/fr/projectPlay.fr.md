## État actuel du jeu

DyingStar est actuellement en phase de **développement**. Seul l'environnement **Universe Testing** est en ligne

Les données de ce serveur de test sont **temporaires** et **ne représentent pas** l'état final du jeu. Elles peuvent être réinitialisées à tout moment sans préavis.

## Compte Discord obligatoire

Pour vous connecter et jouer, un **compte Discord** est indispensable. C'est la seule méthode d'authentification disponible actuellement.

> Aucune inscription par e-mail ou compte dédié n'est proposée pour le moment : la connexion se fait exclusivement via **« Se connecter avec Discord »**.

## Social & Lore : contenu indicatif

Les onglets **Social** et **Lore** sont visibles dans le launcher mais **ne sont pas encore intégrés** au jeu. Ils sont présents à titre indicatif pour donner un aperçu de ce qui arrivera plus tard. Leur contenu n'est pas fonctionnel ni définitif.

## Comment jouer

1. **Ouvrez le launcher** et cliquez sur l'onglet **« Universe Testing »**.
2. **Connectez-vous avec Discord** en cliquant sur le bouton dédié.
3. Dans la section **Fichiers du jeu**, choisissez votre **répertoire d'installation** via le champ prévu (bouton _Parcourir_).
4. Cliquez sur **Télécharger** (ou **Mettre à jour** si le jeu est déjà installé) pour récupérer les fichiers du jeu.
5. Une fois l'installation terminée, cliquez sur **Jouer** pour lancer le jeu.

## Mises à jour

Le launcher vérifie automatiquement si une nouvelle version du jeu est disponible. Si c'est le cas, un message d'alerte s'affiche :

> _« Une mise à jour du jeu est disponible — installez-la avant de jouer. »_

Dans ce cas, cliquez sur **Mettre à jour**. Le jeu ne pourra pas démarrer tant que la mise à jour n'aura pas été appliquée.

## Besoin de réinitialiser vos fichiers ?

En cas de problème (bug, fichiers corrompus, comportement anormal), utilisez le bouton **Vider le cache** disponible dans la section _Fichiers du jeu_ avant de retélécharger le jeu.
