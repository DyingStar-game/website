## Report du test 5 : Server Meshing Dynamic

Bonsoir,

**Mauvaise nouvelle, je suis obligé de reporter le test 5** au lundi suivant, test qui va permettre de tester le server meshing dynamic sur la prod (en août-septembre, c'était un POC). En effet, j'ai identifié un gros souci dans les coordonnées des joueurs, mettant KO les calculs de zones pour le split de server meshing dynamic.

Il semble y avoir un décalage entre les coordonnées dans le serveur horizon et les coordonnées du joueur dans le client (Godot), mettant le bronx dans les calculs (savants :D).

Ça devrait être corrigé le lundi suivant, le reste du code est ok (il manquera un peu de code dans Godot, mais ça sera fait dans la semaine).

Désolé pour le report, on va éviter de vous faire perdre du temps sur un test qui ne servira à rien.

C'est une partie importante, on la soigne du mieux possible pour que ça fonctionne bien dans le futur ^\_^
