Pour rappel, on aura le **test 6 ce mercredi 27 mai à partir de 20h30**.

L'évènement pour s'inscrire est ici : [https://discord.com/events/1399325839665004554/1498914367117197423](https://discord.com/events/1399325839665004554/1498914367117197423) (inscription non obligatoire, mais ça vous fera un rappel 😅)

Voici la liste des choses qu'on va pouvoir tester lors de ce test !

## Launcher

Le launcher a été développé et est prêt à être testé.

Je ferai une news dédiée demain dans la journée avec le lien de téléchargement (version Windows, Linux RPM, Linux DEB et Linux AppImage).

Il faut aller sur le bouton **Universe Testing** en haut.

Il faudra vous **logguer avec votre compte Discord, c'est obligatoire** car on ne souhaite pas gérer de mots de passe.

Vous pouvez ensuite télécharger le jeu en précisant le dossier d'installation.

Voilà, vous pouvez lancer 😉

_Note : la partie sociale est un placeholder, il n'y a pas de code encore, mais ça donne un aperçu de ce qu'il y aura._

## Persistance

On a la persistance côté serveur.

Toutes les données, objets, joueurs sont stockés dans la base de données.

Un redémarrage de serveur devrait voir apparaître tout ce qui a été laissé sur le serveur.

## Spawn - habitation

Grâce à la persistance, lorsque vous vous connectez, un appartement vous est attribué de manière permanente (à terme, vous pourrez le revendre, en acheter d'autres...).

Une plaque devant votre appartement indique votre pseudo.

Je parle d'appartement, c'est une boîte vide pour l'instant, le but est de tester ce système 😄

Bien sûr, vu l'immensité des planètes et de l'univers, on pourra mettre bien assez d'habitations pour tous les joueurs.

## Vocal de proximité

Un vocal de proximité est disponible : lorsque vous passerez près d'une autre personne, vous devriez l'entendre parler.

C'est la feature qui a la plus grande probabilité de moins marcher.

Il y a des touches utiles pour cette partie son :

- touche `m` pour couper le micro
- touche `n` pour couper le son complet du jeu

## Server meshing dynamique

Il y a eu quelques corrections sur le server meshing dynamique, on testera ça au cours du test (seconde partie).

## Page statut

Il y a une [page statut](https://status.dyingstar-game.com/).

Elle indique si les serveurs sont opérationnels et le nombre de joueurs sur le serveur (rafraîchi toutes les 5 minutes).

Ces 2 informations, vous les retrouverez sur le launcher, mais vous pouvez aussi les voir sur cette belle page 😅

## Durée du test

Si pas de problèmes majeurs avec les serveurs, on laissera tourner les serveurs plusieurs heures / jours.
