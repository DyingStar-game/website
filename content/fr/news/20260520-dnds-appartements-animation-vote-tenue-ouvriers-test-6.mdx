## Spawn et appartements

Cette fin de semaine sera poussé dans les dépôts de code le code pour le spawn dans les appartements.

Comment ça fonctionne ?

Lorsque vous spawnez la première fois, le serveur recherche un appartement vide. Dès qu'il en trouve un, il vous est assigné de manière permanente (enfin, dans le jeu plus tard, vous pourrez le revendre pour en acheter un autre ailleurs).

De ce fait, à chaque fois que vous vous connectez, vous respawnerez dans votre appartement.

Ceci est rendu possible grâce au service de persistance.
