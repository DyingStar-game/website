Voici les informations sur l'avancée du projet ces derniers jours.

## C'est technique, ça fait classe

Au niveau tech, plusieurs nouveautés :

- **Planet Tech v1** : elle a été poussée sur le dépôt de code. La génération des niveaux et des biomes sont dessinés dans QGIS, puis la planète est exportée (HEALPix) dans Godot. Il reste du travail encore sur les terrains, les biomes... La lune 1 de la planète Tarsis 5 (géante gazeuse) a commencé à revêtir ses biomes.
- **Server Meshing Dynamic** : le code est poussé (serveur Godot + serveur Horizon). Il reste la suppression de serveurs Godot et un problème quand on marche et qu'on passe d'un serveur à l'autre : l'information d'avancement est perdue et on est stoppé net ; bonne nouvelle, une modification est définie et va être faite dans les prochains jours afin de corriger ce problème ^\_^
- **Persistance non voulue** : quand un joueur se déconnectait du jeu (problème vu lors du dernier test), le joueur restait sur le serveur Godot. Un fix a été fait ^\_^
- **Kubernetes** : les environnements locaux (pour les devs), pré-prod (pour les tests) et prod (pour la première version, pas encore là hein !) sont créés. Ça permet de lancer tous les services pareillement, quel que soit l'endroit.

Pour plus d'informations, voir [ici](https://discord.com/channels/1399325839665004554/1428454518269677568/1497955022447841280).

## Audio

### Wwise

Godot intègre le streaming, le mixage, les effets... De ce fait, on enlève la couche Wwise pour gérer directement dans l'audio de Godot (avec les sons dans le système de fichiers du jeu directement). Ça amène une grosse simplification de la gestion audio pour le même résultat.

### Vocal in-game

Le travail a débuté pour intégrer LiveKit et donc l'audio entre joueurs.

Pour le moment, une room est créée par le serveur Horizon et intègre le joueur dedans. Le joueur reçoit son token de connexion et peut se connecter.

Cette première itération permet de tester la techno et de se familiariser avec. Juste après, on modifiera pour gérer l'audio de proximité.

Pour les vocaux de groupes / parties, ça sera un peu plus tard.
