## Current status of the game

DyingStar is currently in **development**. Only the **Universe Testing** environment is online.

Data on this test server is **temporary** and **does not reflect** the final state of the game. It may be reset at any time without notice.

## Discord account required

To log in and play, a **Discord account** is required. It is currently the only available authentication method.

> No email sign-up or dedicated account is offered at this time: logging in is done exclusively via **"Login with Discord"**.

## Social & Lore: for reference only

The **Social** and **Lore** tabs are visible in the launcher but **are not yet integrated** into the game. They are shown for reference, to give a preview of what's to come. Their content is not functional or final.

## How to play

1. **Open the launcher** and click the **"Universe Testing"** tab.
2. **Log in with Discord** by clicking the dedicated button.
3. In the **Game Files** section, choose your **installation directory** using the field provided (_Browse_ button).
4. Click **Download** (or **Update** if the game is already installed) to get the game files.
5. Once installation is complete, click **Play** to launch the game.

## Updates

The launcher automatically checks whether a new version of the game is available. If so, an alert message is displayed:

> _"A game update is available — install it before playing."_

If this happens, click **Update**. The game will not be able to start until the update has been applied.

## Need to reset your files?

If you run into an issue (bug, corrupted files, unusual behavior), use the **Clear Cache** button available in the **Game Files** section before redownloading the game.
