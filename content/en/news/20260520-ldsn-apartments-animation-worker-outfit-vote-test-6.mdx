## Spawning and apartments

At the end of this week, the code for spawning in apartments will be pushed to the code repositories.

How does it work?

When you spawn for the first time, the server looks for an empty apartment. As soon as it finds one, it's assigned to you permanently (well, later in the game you'll be able to sell it to buy another one somewhere else).

As a result, every time you log in, you'll respawn in your apartment.

This is made possible thanks to the persistence service.
