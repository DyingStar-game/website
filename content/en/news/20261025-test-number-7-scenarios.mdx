This **Monday evening at 8:30 PM**, we're going to test **dynamic server meshing**.

We'll run several tests to check how it behaves:

- the health of the Godot servers
- the issues players run into (stuttering, complete freezes...)
- network traffic

## Moving from one server to another

I know some of you will want to move from one server to another: you'll be able to! In the debug panel, you'll see in real time how far the server border is from wherever you're looking.

It works well both on foot and in a vehicle. You may get a mini freeze if the server you're moving onto is running below 50 - 55 TPS (yes, the servers run at 60 TPS ❤️).

## Split, merge and connection queue

For your information, server split and merge have already been working for several weeks. We have **30 Godot servers** that can start on demand: everything is automated and managed by the Horizon server.

There is a queue if there are too many connections at the same time. Normally, you'll get onto one of the servers within a few seconds to a few dozen seconds (it will depend on whether there are 200 or 1000 of you :D).
