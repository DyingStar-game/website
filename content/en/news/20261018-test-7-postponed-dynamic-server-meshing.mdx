We have no choice but to postpone test 7: the internet connection (fibre) used by a large part of the servers has been down since Friday afternoon. It is still not operational, so we are rescheduling the test for Monday 26 October.

Sorry for the inconvenience, which is beyond our control.

On Friday, quite a few patches were made and the servers were able to host 2150 NPCs (which connect just like players), so the test with real players will let us validate this networking part.
