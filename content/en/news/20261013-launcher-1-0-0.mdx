## Launcher 1.0.0 🔥

The launcher is stable enough to move to **version 1.0.0**

Changelog:

- Profile editing added: faction, biography and RP sheet.
- Organization management added: info, invitations, members, ranks and leadership; option to leave an organization; invite a player from their profile.
- Social page split into Friends and Organizations, each with its own list, a search field and pending requests.
- Header split into two bars: the launcher on top, the current universe below (Home, Social, Changelog and account).
- Login moved to the top right; when logged out, the Play button is replaced by "Log in with Discord".
- Counters added for pending friend requests and unread changelog versions.
- Test environment flagged on every page; the launcher now opens on it.
- Lore page removed.
- Crackling interface sounds fixed.
- Home page redesigned: the universe shown as a full-screen image slideshow, and a single bar at the bottom with the server status, the game status and its main action (install, update, log in, play).
- Game download: pause, resume (even after closing the launcher) and cancel; speed and remaining time displayed.
- Game files (version, install directory, cache) moved behind a ⚙ button next to the main action.
- An available game update now shows the installed version and the new one, with a link to its changelog.
- Friends on the home page listed alphabetically, all of them.
- Notifications (profile saved, organization created, cache cleared…) displayed in a corner of the screen.
- Logging out no longer opens a page in the browser; the next login asks for the account again.
- Friend list cleared on logout.
- Screenshots and videos in the game folder kept during an update.

Many thanks to @YnotnA who worked a lot on the code, as well as to everyone who helped him (bugs, ideas...)

To download it, head over here: [https://github.com/DyingStar-game/launcher/releases/latest](https://github.com/DyingStar-game/launcher/releases/latest)
