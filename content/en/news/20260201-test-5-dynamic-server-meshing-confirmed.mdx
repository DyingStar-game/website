## Test 5: Dynamic Server Meshing: CONFIRMED 🔥

Good evening everyone, tomorrow night's test (Monday, February 2 at 9 PM) is confirmed.

We'll be testing **dynamic server meshing**. There won't be any new 3D models since test 4; the focus is really on the network side (stability and dynamic server meshing).

For this test, the server split will be based on the number of players (but eventually it will be based on the CPU load of the Godot servers).

You're welcome to stream this test — if we get a lot of people, it could be pretty cool!

Tomorrow at 9 PM, 2 archives will be provided:

- Windows client
- Linux client

I'll try to write an article on how dynamic server meshing works by tomorrow evening (about 30% likely, as I still have a few bugs to fix before then).

See you tomorrow!
