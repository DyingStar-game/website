## Proximity voice chat

Last week, proximity voice chat was implemented in DyingStar. When you walk past someone, you'll hear them (through their microphone), louder or quieter depending on the distance between you.

We use LiveKit for this; only the room management part goes through our servers, the audio uses WebRTC and therefore goes directly between players.

Participant IDs are generated for each player, which improves security (we avoid using the user ID directly).

You can find a test video [here](https://discord.com/channels/1399325839665004554/1399753890584330341/1500229322735095).

## Horizon, services and persistence

We held a review this weekend on services and persistence.

For services, we need to modify the websocket bridge between Horizon and external services. For example, the proximity voice part is currently a Horizon plugin, but it should be an external service. However, we need to modify this bridge in order to externalize it. Work to be done in the coming weeks.

For persistence, given that Horizon loads everything, and that Dgraph has no official Rust support, we're looking into PostgreSQL. We're currently checking whether it can meet our needs (horizontal scalability, parent/child management, spatialization).
