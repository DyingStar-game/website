Launcher 0.4.0 is available, still for Windows and Linux

## What's inside

- **Social**: friends, friend requests and organizations now go through the game's social service, with a player search
- **Player and organization pages**, opened by clicking on a player or an organization; Back takes you right where you were
- Fixed the launcher window not showing up on Linux in a Wayland session (only the sound was there)
- The header adapts to narrow windows: sections and the universe selection move into the menu
- Statuses (member, friend, request sent…) no longer look like buttons; every button now shows the hand cursor
- New language menu in the header, plus tooltips on the header buttons
- Menus and the volume setting can be used with the keyboard
- Pages and lists display a preview of their content while loading

It's right here: [https://github.com/DyingStar-game/launcher/releases/tag/v0.4.0](https://github.com/DyingStar-game/launcher/releases/tag/v0.4.0)

Beware, friends are still offline for now.
It should work within 1 to 3 days (the server-side code isn't ready yet), and no launcher update will be needed 😉
