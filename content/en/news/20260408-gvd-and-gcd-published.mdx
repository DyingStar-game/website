## GVD and GCD Published

### GVD

The GVD (Game Vision Document) has been published on the wiki: [https://developer.dyingstar-game.com/docs/project/GVD/](https://developer.dyingstar-game.com/docs/project/GVD/)

This document presents the overall vision of the game.

### GCD

The GCD (Game Concept Document) has been published on the wiki: [https://developer.dyingstar-game.com/docs/project/GCD/introduction/](https://developer.dyingstar-game.com/docs/project/GCD/introduction/)

This document goes into a bit more detail about the game's pillars and certain aspects (it is more detailed than the GVD).

We've included the MVP in it, which will be the first version of the game with some initial gameplay. Several mechanics and gameplay elements will be simplified for this first version and will be expanded / modified in later versions.

## GDD Currently Being Written

The GDD (Game Design Document) is currently being written and details every aspect of the game.

The mining and planets sections have been added and are still being fleshed out.

The player section and the 3D section are being written.

If you'd like to help write certain sections, grab the matching role and get in touch with the lead or sublead of that section to start writing. Some leads and subleads also post calls for contributions. If needed, let us know on Discord.

## Planet Tech

Planet Tech is making great progress. The HEALPix format has been validated (better precision across the whole planet, even at the poles). Quadtree is the usual approach, but it wasn't fully satisfactory; the HEALPix format suits our needs much better (a technology mostly used by scientists).

We use QGIS to create the maps, then export them into Godot. The documentation is being written. A presentation was given during yesterday's public lead meeting. We can schedule another presentation if some of you are interested in this part, just say so on Discord.

The code will be pushed to the repository within a few days.

## Game Code

The Planet Tech code will be pushed to the repository within a few days, and the mining-related branches will be merged afterwards (several mining-related features were already completed in late 2025).

We're thinking about running a new test with these elements, but there's no date yet; we need to make a bit more progress on the code first.
