## Feedback on test 6

Quite a few network issues.

Some of the issues preventing players from seeing each other have been fixed.

The servers are now available at all times; they are updated continuously (the client too, via the launcher) whenever code is validated.
So you can play whenever you like ^\_^

The launcher worked well; a bug was found the day before yesterday and has been fixed (not released yet, but it will be shortly).

The focus is now on stabilising the network layer. To do so, the last 2 parts are under development ([NPC management](https://discord.com/channels/1399325839665004554/1432687821772161116/1510912011289231372) and Horizon multi-server management — yes, server meshing on top of server meshing :D). This work will span the next 4 weeks.

The menu is being reworked by the UI and development teams.

## Next test

With the servers always online, we'll be able to run small tests from time to time.

The next big test should take place during July, with:

- stabilised network layer
- NPCs
- vehicle (at least the gameplay part, the design is not certain)
- player animation
- a few more assets (currently being created)
