Here is the latest on the project's progress over the past few days.

## It's technical, it's classy

On the tech side, several new things:

- **Planet Tech v1**: it has been pushed to the code repository. Level generation and biomes are drawn in QGIS, then the planet is exported (HEALPix) into Godot. There is still work to do on terrains, biomes... Moon 1 of the planet Tarsis 5 (a gas giant) has started putting on its biomes.
- **Dynamic Server Meshing**: the code has been pushed (Godot server + Horizon server). What remains is the removal of Godot servers and an issue when walking from one server to another: the movement information is lost and you stop dead in your tracks; good news, a change has been defined and will be made in the coming days to fix this problem ^\_^
- **Unwanted persistence**: when a player disconnected from the game (issue seen during the last test), the player stayed on the Godot server. A fix has been made ^\_^
- **Kubernetes**: the local (for devs), pre-prod (for tests) and prod (for the first release, not there yet, mind you!) environments have been created. This allows all services to be launched the same way, wherever they are.

For more information, see [here](https://discord.com/channels/1399325839665004554/1428454518269677568/1497955022447841280).

## Audio

### Wwise

Godot has built-in streaming, mixing, effects... So we are removing the Wwise layer to handle everything directly in Godot's audio system (with the sounds directly in the game's file system). This brings a major simplification of audio management for the same result.

### In-game voice chat

Work has started on integrating LiveKit, and therefore voice between players.

For now, a room is created by the Horizon server, which puts the player in it. The player receives their connection token and can connect.

This first iteration lets us test the technology and get familiar with it. Right after, we'll modify it to handle proximity voice.

Group / party voice chat will come a bit later.
