## Play test #4 postponed

Following the multi-parent handling added to the gorc part (you only see what's around you), which was coded the day before yesterday, a series of intertwined bugs makes the game unplayable (movements work on the server side but aren't reflected on the client side, plus some other issues with box spawns...). I tried to fix it tonight, but the code is fairly complex, and I'd rather take the time to fix it properly so it stays maintainable going forward (= make the code simpler and functional).

As a result, **I've decided to postpone the play test by one week, to Monday, December 8 at 9:00 PM**.

A tough decision, but I'd rather not mobilize a lot of people for nothing, since it would be completely unplayable.

Sorry for the delay. These are still technical tests, and the goal is to properly stabilize this networking part so we can build the game as easily as possible afterwards.
