As a reminder, **test 6 will take place this Wednesday, May 27, starting at 8:30 PM**.

The event to sign up is here: [https://discord.com/events/1399325839665004554/1498914367117197423](https://discord.com/events/1399325839665004554/1498914367117197423) (signing up isn't mandatory, but it will send you a reminder 😅)

Here is the list of things we'll be able to try out during this test!

## Launcher

The launcher has been developed and is ready to be tested.

I'll post a dedicated news tomorrow during the day with the download link (Windows, Linux RPM, Linux DEB and Linux AppImage versions).

You need to click the **Universe Testing** button at the top.

You will have to **log in with your Discord account, this is mandatory** because we don't want to manage passwords.

You can then download the game by specifying the installation folder.

That's it, you can launch 😉

_Note: the social section is a placeholder, there's no code behind it yet, but it gives you a preview of what's coming._

## Persistence

We now have server-side persistence.

All data, objects and players are stored in the database.

After a server restart, everything that was left on the server should reappear.

## Spawn - housing

Thanks to persistence, when you log in, an apartment is permanently assigned to you (eventually, you'll be able to sell it, buy others...).

A nameplate in front of your apartment shows your username.

I say apartment, but it's an empty box for now; the goal is to test this system 😄

Of course, given the vastness of the planets and the universe, we'll be able to fit more than enough homes for all players.

## Proximity voice chat

Proximity voice chat is available: when you walk near another person, you should be able to hear them talk.

This is the feature most likely to not work properly.

There are some useful keys for the audio part:

- `m` key to mute the microphone
- `n` key to mute all game sound

## Dynamic server meshing

There have been a few fixes to dynamic server meshing, we'll test that during the test (second part).

## Status page

There is a [status page](https://status.dyingstar-game.com/).

It shows whether the servers are up and the number of players on the server (refreshed every 5 minutes).

You'll find both pieces of information in the launcher, but you can also check them on this nice page 😅

## Test duration

If there are no major issues with the servers, we'll keep them running for several hours / days.
